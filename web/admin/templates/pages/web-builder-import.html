Upload the zip of a finished static website (its HTML pages with their CSS, JavaScript, fonts and images). Pursae Web Builder imports every page one to one as code sections, splits the shared header and footer into Theme Builder templates and keeps the design's files as a design kit. Nothing is written to your site until you start the import.

3. Options

{{if .A.Folders}}{{$col := .Collections}}{{end}}

Shown in the kit list and in the titles of the new templates.

{{if .A.KitExists}}

A design kit with this slug exists ({{.A.KitFiles}} files). Importing replaces its files.

{{end}}
Header and footer

The shared header and footer become templates that every page uses. Without this each page keeps its own copy.

Menu

The menu is assigned to the primary location and fills the design's list with the design's own markup; add, rename and reorder items in Appearance › Menus. Only made when the menu reproduces the list exactly.

Collections
{{range .A.Folders}}
{{end}}

The pages of a ticked folder that share one layout become page content (title, content, custom fields) under one Theme Builder single template, at the same addresses; lists of those pages on other pages become loops. Pages that do not fit stay pages.

Front page {{if not .A.HasFront}}

The site has no index.html at its top.

{{end}}
Status

A large site takes a while; keep this page open.
