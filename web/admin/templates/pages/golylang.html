About Pursae Multi Language

Pursae Multi Language is Pursae's built-in multilingual plugin, a clone of Polylang Pro. Add the languages here, then translate posts, pages, categories and tags from their lists and editors, strings under Translations, and choose how URLs carry the language under Settings. Add a language switcher with the Language switcher block, the Languages item of Appearance › Menus, or {{"{{"}}pll_the_languages .{{"}}"}} in a theme.
