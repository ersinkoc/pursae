Build your own theme

Back to Themes

Anyone can build a theme for their own site, also with an AI assistant such as Claude Code.

The developer documentation is written so that an AI can follow it step by step, and Pursae also exposes it to AI agents over MCP.

Theme package (native theme)

A theme.json file, Go html/template files and assets, zipped and uploaded. No code runs and the package is not signed: it is checked by its SHA-256 hash.

my-theme/
  theme.json
  templates/
    index.html
    header.html
    footer.html
  assets/
    style.css

Start from the starter example in the documentation. Set PURSAE_THEMES_DIR for a live development loop.

Web Builder theme

Design the header, footer and templates visually with Pursae Web Builder (Theme Builder), shown by the bundled Hello Pursae theme.

You can also import your own HTML design or a theme kit.

Just for my own site

No submission is needed. Follow the documentation to write, zip and upload your theme.

Core updates never change uploaded theme packages. Edit a copy instead of editing a bundled theme in place, so updates of the bundled theme still reach you.
