Plugins extend and expand the functionality of WordPress Go. Plugins are written in Go (or any language that compiles to WebAssembly), run in a sandbox and must be signed. Install them from the WordPress Go Hub marketplace below, or upload a plugin package in .zip format by clicking the button above. Learn how to build one.
