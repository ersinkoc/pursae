Pursae

Pursae: A Rebuilt Version of WordPress Using GO

The WordPress you know, rewritten from the ground up in Go: one fast binary, PostgreSQL, the real admin, the block editor, a page builder and sandboxed plugins.

Version {{.Version}}{{.Go}}PostgreSQL 17GPL

Core

What you get out of the box.

One binary

Admin, REST API, themes, media and cron compiled into a single Go binary with its assets embedded. No PHP, no extensions, no FPM pool.

PostgreSQL 17

Typed tables with JSONB where flexibility helps, and full-text search on a generated tsvector.

The real WordPress admin

The WordPress admin markup and CSS you already know, ported 1:1, running on a Go server.

Secure by default

Protections live in the core and are on from the first request. Multi-role capabilities with per-user allow and deny.

Sandboxed plugins

Plugins are signed WebAssembly modules that ask for permissions on activation. A misbehaving plugin is stopped, not your site.

No Gravatar

Avatars come from your own Media Library. Nothing about your visitors is sent to a third party.

Plugins and features

Built into the binary. Switch on what you need from the Plugins screen.

Pursae Editor

The block editor on Pursae’s REST API. The Classic Editor is built in too.

Pursae Web Builder

A visual page and theme builder: edit in place, publish fast static HTML. Theme Builder with display conditions.

Pursae Commerce

A full store: products, orders, checkout, payments and ready-made store themes.

Pursae Multi Language

Translate posts, pages, terms and menus, with a language switcher.

Pursae Contact Form

Drag-and-drop forms, mail templates and submissions.

Pursae Custom Fields

Field groups for posts, terms, users and options, with a visual rule builder.

Pursae SEO

Titles, meta, Open Graph, schema, sitemaps, redirects and an analysis box in both editors.

Pursae Cache

Page cache with tag-based purges, a crawler and page optimizations behind any web server.

Pursae CDN

Rewrite assets to a pull CDN and purge Pursae Cache and your CDNs together.

Pursae Headless

Use Pursae as a content backend for your own front end.

Pursae Security

Login protection, two-factor authentication, sessions and an audit log.

Pursae Maintenance

Maintenance and coming-soon modes that never get cached.

Pursae SMTP

Reliable email delivery with logs and a dashboard report.

Pursae Cookie

Consent banner and cookie controls.

Ecosystem

Everything around the core: marketplace, packages, SDK, themes and docs.

Pursae Manager

The marketplace for plugins and themes, licenses, channels, statistics and core releases.

Signed packages

Plugins and themes install from the Manager after their checksum and signature are verified.

Plugin SDK

Write plugins in Go (or any language that compiles to Wasm) with the Pursae SDK and example plugins.

Themes

Twenty Twenty-Five, the blank-canvas Hello Pursae, and a growing library of theme packages with one-click demo import.

Developer docs

Guides for plugins, themes, the REST API, hooks and operations, all open and searchable.

Self-updating core

Update from the dashboard: the new binary is verified, replaces the running one, and rolls back if it does not start.
