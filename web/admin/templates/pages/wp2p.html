Move a whole WordPress site here: users (they keep their passwords), posts, pages, media, menus, settings and the WooCommerce store with its products, orders, customers and coupons. Install the WP to Pursae plugin on the WordPress site (Tools › Move to Pursae), then use one of the two ways below. What moves and what does not.

1. Send it from WordPress (recommended)

Generate a one-time migration token here and paste it into the plugin. The plugin uploads the encrypted package straight to this site, resuming if the connection drops, and the import starts on its own.

2. Upload a package

In the plugin choose Download a package; it gives you a .wp2p file and a package key. Upload both here (maximum size: {{.MaxUpload}}). For very large packages the command line is faster: pursae import wordpress site.wp2p --key=…
