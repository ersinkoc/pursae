# Ironbeam Construction

A bold corporate theme for construction and engineering companies: safety yellow and steel grey, condensed industrial headings, hazard-stripe accents, a days-without-incident counter, services, completed projects, safety figures, careers and project-update posts.

Category: **construction** · Style: Safety yellow and steel, condensed industrial type

## Highlights

- A safety strip with a days-without-incident counter (a number setting) in the header and under the hero
- Hazard-stripe accents, condensed uppercase headings and square or rounded corners
- Service cards, a safety-yellow figures band, project tiles with captions and a careers block
- Project updates as cards or wide rows
- Header as an iron, safety-yellow or white bar
- Responsive down to 360px with an accessible mobile menu (Escape closes it), visible focus states and `prefers-reduced-motion` support

## Customizer

**Brand & Type**: Accent (safety yellow); Steel; Iron (darkest); Typefaces; Hazard stripes under the header and above the footer; Corners.

**Header & Safety Counter**: Header style; Keep the header visible while scrolling; Days without a lost-time incident; Counter label; Strip text; Header button label; Header button link.

**Front Page Hero**: Hero image; Label above the heading; Heading; Text; Button label; Button link.

**Updates & Footer**: Post list layout; Sidebar; Show featured images; Show the author on posts and cards; Footer headline; Footer text.

## Demo content

Appearance › Themes › Import Demo Content adds 8 posts, 7 pages (We build what cities run on, Project updates, Projects, Safety record, About Ironbeam, Careers, Request a bid), 5 categories, 11 images, a main menu with submenus, a footer menu, sidebar and footer widgets and the Customizer values shown in the screenshot. The front page is a static page built from blocks; the template `page-wide` is used for full-width pages. All names, firms, addresses and numbers are fictional.
