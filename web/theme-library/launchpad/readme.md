# Launchpad

A bright landing theme for SaaS products and startups. A gradient mesh hero with a product screenshot in a browser frame, a floating pill header, feature grids, pricing tiers, testimonials and a changelog blog laid out as a timeline. Plus Jakarta Sans throughout, with an optional Instrument Serif italic pairing for headings.

## Highlights

- Static front page with an announcement bar, a badge, two buttons and a framed product screenshot
- Three mesh colors and an accent you can change live; an optional dark mode
- Changelog as a dated timeline or a card grid, with `New`, `Improved` and `Fixed` labels (`tag-new`, `tag-improved`, `tag-fixed`)
- Block classes for sections: `logo-row`, `feature-grid` + `feature-icon`, `pricing` + `tier--featured`, `testimonials`, `stats`, `check-list`, `cta-band`, `section-soft`
- `page-landing` template for full-width pages without a title band

## Customizer

- **Launchpad Colors**: accent, mesh colors 1–3, dark mode
- **Launchpad Layout**: font pairing, header style (floating pill / full bar), changelog layout, sidebar, container width, featured images, author names, sticky header
- **Launchpad Hero & Calls to Action**: announcement bar and its text and link, hero badge, heading, text, primary and secondary buttons, product screenshot, footer text

## Demo content

“Orbitly”, a fictional planning tool: a designed home page, Features and Pricing landing pages, About and Contact, and eight changelog posts across Releases, Improvements and Company. All text and images are original.

Fonts: Plus Jakarta Sans and Instrument Serif, SIL Open Font License 1.1.
