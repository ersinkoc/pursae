# Pulse Fit

A high-energy gym and fitness studio theme. Electric lime on black (or white), Bebas Neue headlines with Barlow text, angled section edges and a scrolling class ticker.

## Highlights

- Full-bleed hero with a live-dot kicker, huge headline and two buttons; a scrolling ticker below it (paused for reduced motion)
- Class schedule table (`schedule`, with `intensity` labels), program tiles (`program`), membership plans (`plan`, `plan is-featured`) and trainer cards (`trainer`, `role`)
- Workout posts: numbered `workout` lists and `stat-row` columns
- Journal in a magazine layout (first post large) or an even grid, optional sidebar
- Lime call-to-action band in the footer with the main button

## Customizer

- **Colors & Type**: accent, second accent, dark mode, typefaces, angled section edges
- **Header & Hero**: sticky header, main button label and link, hero image, heading, text, second button, ticker text
- **Journal & Footer**: journal layout, sidebar, footer slogan, footer text

## Demo content

Eight journal posts (kettlebell circuit, first week of strength training, spin guide, nutrition, recovery and studio news), a designed Home page, Class schedule with a Trainers sub-page, Membership and Contact; main and social menus, sidebar and footer widgets. All text and images are original.

Fonts: Bebas Neue and Barlow, SIL Open Font License 1.1.
