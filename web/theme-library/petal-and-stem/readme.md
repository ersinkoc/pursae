# Petal & Stem

A florist and flower studio theme with hand-drawn botanical illustrations, an elegant italic serif and a shop-like bouquet catalogue.

## Features

- Front page hero with an arched photo, botanical ornaments and an order button
- Bouquet Catalogue page template (`page-catalogue`): product cards (`bouquet` groups inside `bouquet-grid` columns) with prices and order buttons, two to four per row
- Wedding & events page, care-guide posts with numbered care steps (`care-card` group with a `care-steps` list), leaf-bulleted lists
- Announcement bar, header order button, inline or stacked header, grid or list journal, optional sidebar
- Botanical SVG illustrations you can switch off, accessible focus states, reduced motion, responsive down to 360px

## Customizer

- **Colors & Type** — peony, moss, background, text; three type pairings
- **Layout** — header, bouquets per row, journal layout, sidebar, botanical illustrations, featured images, author
- **Shop Details** — announcement bar, order button label and link, hero photo, footer text

## Demo content

Import it from Appearance › Themes: a florist front page, the bouquet catalogue, Weddings &amp; Events, Delivery, About and Contact pages, eight care guides and studio stories, menus, widgets and comments.

All demo text is original and every demo image is original generated artwork, free to use with the theme.
