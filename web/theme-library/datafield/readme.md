# Datafield

A research notebook for data science and statistics writing. Paper-white pages with graph-paper gridlines, a sparkline across the masthead, a serif reading face with monospaced labels, numbered figure captions, footnotes, booktabs-style data tables and notebook-style code cells (“In [1]:”). Series colors run through the menu, category keys and charts.

## Highlights

- Home page intro over gridlines, then an index table of entries (number, date, title, excerpt, thumbnail) or figure cards
- Figures numbered automatically (“Figure 1.”), tables labelled, code blocks numbered as notebook cells
- Footnotes: `<sup class="fn"><a href="#fn-1">1</a></sup>` and an ordered list with the class `footnotes`
- Block classes: `series-nav`, `note-box`, `stat-row` + `stat`
- Category colors for `notebooks`, `methods` and the series categories

## Customizer

- **Datafield Colors**: series colors 1–3, paper, ink, graph-paper gridlines
- **Datafield Reading**: font pairing (Newsreader / Source Sans 3 / system), post list layout, text width, sidebar, figure numbering, featured images, author names
- **Datafield Intro & Footer**: intro on/off, label, heading, text, footer text

## Demo content

“Margin of Error”, a fictional data notebook: eight posts across Essays, Notebooks, Methods and two multi-part series, with charts, tables, code and footnotes; About, Series and Contact pages. All text and figures are original.

Fonts: Newsreader, Source Sans 3 and Spline Sans Mono, SIL Open Font License 1.1.
