# Byte Notes

A dark-first developer blog for WordPress Go. Glowing violet-to-cyan accents, a card grid or a
compact list of notes, code blocks styled like editor windows (with a language label for
`lang-go`, `lang-sql`, `lang-css`, `lang-bash`, `lang-js`, `lang-dockerfile` classes), tag
pills, a newsletter box and a light/dark switch that remembers each reader's choice.

## Features

- Dark and light color schemes; the Customizer sets the default (dark, light or the reader's
  system setting) and whether readers get a toggle in the header.
- Card grid with a wide feature card for the newest note, or a compact list.
- Styled code blocks, inline code, keyboard keys, callouts (`bn-callout` group class),
  quotes and columns.
- A home intro panel with a search prompt and an optional background image.
- A newsletter box under every page with your own heading, text, button label and link.
- Sidebar and footer widget areas, primary and footer menus, sticky header.
- Self-hosted Inter, Space Grotesk and JetBrains Mono (SIL Open Font License), ~100 KB.

## Customizer

**Byte Notes Colors**: accent color, second accent, default color scheme, show the toggle.
**Byte Notes Layout**: card grid or list, font pairing (Space Grotesk + Inter, JetBrains Mono
headings, or system UI), container width, sidebar, featured images, author names, sticky header.
**Byte Notes Home Intro**: show the panel, kicker, headline, text, background image.
**Byte Notes Newsletter & Footer**: show the box, heading, text, button label, button link,
footer text.

## Demo content

Eight original articles about backends, databases, DevOps, frontend and tooling with code
samples, four pages (About, Contact, Uses, Newsletter), menus, widgets and comments. The
artwork in `demo/images` was generated for this theme.
