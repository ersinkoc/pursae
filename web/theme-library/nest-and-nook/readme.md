# Nest & Nook

An interior design studio and home decor blog theme: quiet neutral tones, generous white space and big room photography.

## Features

- Full-bleed room hero with a caption card on a static front page
- Masonry, grid or list journal with varied image shapes
- Room tiles, room-by-room galleries, before/after comparisons (`before-after` columns with image captions as labels) and numbered shop-the-look panels (`shop-look` group with a `shop-list` list)
- Split or centered header, optional fine-line page frame, three container widths, optional sidebar
- Full-width page template (`page-wide`), accessible focus states, reduced motion, responsive down to 360px

## Customizer

- **Colors & Type** — accent, linen, background, text; three type pairings
- **Layout** — journal layout, container width, header, sidebar, page frame, featured images, author
- **Home Page & Footer** — hero photo, hero label, footer text

## Demo content

Import it from Appearance › Themes: a studio front page, eight journal posts with galleries, before/after and shop-the-look lists, Rooms, Services, About and Contact pages, menus, widgets and comments.

All demo text is original and every demo image is original generated artwork, free to use with the theme.
