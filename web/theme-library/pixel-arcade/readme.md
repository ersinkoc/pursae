# Pixel Arcade

A retro-futuristic dark theme for video game news and reviews, made for WordPress Go.

- An 8-bit HUD bar, a header with a pixel invader and a blinking cursor, and a ▶ selection pointer in the menu.
- A front-page hero framed like a game screen with a health bar, then review cards with score badges, an upcoming-releases table styled as a high-score list, platform buttons and an "insert coin" newsletter box.
- Verdict boxes with a big score and power-ups/glitches lists (use the `pa-verdict`, `pa-score`, `pa-pros` and `pa-cons` classes on groups and paragraphs).
- Platform chips from categories and tags, a sidebar on the left, right or off, grid or list cards.
- A `page-wide` template for calendars and tables.

## Customizer

**Colours & Effects**: coin yellow accent, neon cyan links, hot pink shadows, screen colour, CRT scanlines, stepped pixel corners, font pairing (Press Start 2P & Chakra Petch, Chakra Petch only, system fonts).
**Layout**: grid or list posts, sidebar right/left/none, featured images, author names, sticky header.
**Front Page Hero**: hero image, kicker, heading, button label and link, footer text.

## Demo content

Nine posts (reviews, a preview, news, guides and a feature), a designed home page, a release calendar, About with a review policy, and Contact. All text and pixel artwork are original.

Fonts: Press Start 2P and Chakra Petch (SIL Open Font License), self-hosted.
