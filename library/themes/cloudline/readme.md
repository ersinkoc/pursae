# Cloudline

A crisp, trustworthy theme for managed IT, cloud and cybersecurity companies. A live status bar, a split hero with an uptime badge, service cards, an SLA figures band, plan tiers, onboarding steps and a blog for case studies and security advisories, where advisories get a red severity flag automatically.

## Highlights

- Status bar with a pulsing indicator and a 24/7 support number
- Header in white, primary blue or deep navy; rounded or square corners
- Insights as cards or rows, with the sidebar on the right, the left or off
- Block classes: `services` + `service-icon`, `sla` + `figure`, `plans` + `plan--recommended` + `plan-flag`, `steps`, `advisory-box` (`is-high`) with `severity`, `result-figures`, `cta-band`, `section-tint`
- Posts in the `security-advisories` category are flagged in lists and on the post page

## Customizer

- **Cloudline Brand**: primary blue, deep navy, section tint, header style, corner style, font pairing
- **Cloudline Layout**: sidebar, post list layout, featured images, author names, sticky header
- **Cloudline Status & Hero**: status bar on/off, status message, support phone, header button, hero kicker, heading, text, button, uptime badge, hero image, footer text

## Demo content

A fictional managed-services firm: home, Services & plans, About, Contact and an Insights blog with two security advisories, three case studies, two guides and a company update. All text and images are original.
