# Quiet Hours

An ultra-minimal, text-first blog theme for Pursae. One calm column, a monospaced voice,
posts listed under their year, and a light/dark switch that remembers each reader's choice.

## Features

- **Posts by year**: the blog, archives and search list titles under year headings; switch to
  titles with excerpts in Customize.
- **Light and dark**: follow the visitor's system, or default to light or dark. The small switch in
  the header stores the reader's choice in their browser only.
- **Three font pairings**: monospace throughout (IBM Plex Mono, self-hosted), or mono details with
  sans-serif or serif text from the system font stack.
- **Calm by default**: featured images are hidden on posts unless you turn them on; nothing moves
  unless the reader moves it, and motion is switched off for `prefers-reduced-motion`.
- Footer widget area, primary menu with a submenu, footer links menu, threaded comments, editor styles.

## Customizer

| Section | Setting | What it does |
|---|---|---|
| Colors | Accent color | Year markers, link hover, focus rings (live) |
| Colors | Paper / Night | Light and dark background colors (live) |
| Colors | Default color scheme | Auto, light or dark before the reader chooses (live) |
| Colors | Show the light/dark switch | Hides or shows the header switch (live) |
| Type & Layout | Font pairing | Mono, mono + sans, mono + serif (live) |
| Type & Layout | Column width | Narrow, normal or wide column (live) |
| Type & Layout | Base font size | 14–20 px (live) |
| Content | Post list | Titles by year, or titles with excerpts (live) |
| Content | Show dates in post lists | Month and day beside each title (live) |
| Content | Show featured images on single posts | Off by default (live) |
| Content | Home page introduction | A short paragraph above the list on the blog home |
| Content | Footer text | Replaces the copyright line |

## Demo content

"A Quiet Notebook": eight entries across three years (essays, notes, reading, walks), About with
Now and Colophon sub-pages, Contact, a main menu with a submenu, footer links, three footer widgets
and a few comments. All text and images are original.
