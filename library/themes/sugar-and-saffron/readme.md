# Sugar & Saffron

A baking and dessert blog theme for a pastry chef: blush and cream with a saffron accent, flowing script headings and arched photo frames.

## Features

- Static “about the baker” front page: arched portrait, script greeting, seasonal collection tiles, recipe tiles and a newsletter box
- Recipe cards inside posts (`recipe-card` group) with bake-time chips, heart-bulleted ingredients, script step numbers and a print button (link to `#print`)
- Grid or list recipe archive, arch / rounded / square image shapes, optional sidebar left or right
- Centered or inline header, optional announcement bar, scalloped blush footer with widgets and social links
- Accessible focus states, reduced motion support, print styles, responsive down to 360px

## Customizer

- **Colors & Type** — accent, blush, background and text colors; three type pairings
- **Layout** — header style, grid or list, image shape, sidebar, featured images, author, sticky header
- **Home Page & Footer** — baker photo, greeting line, announcement bar, footer text

## Demo content

Import it from Appearance › Themes: eight recipes and baking notes, a designed front page, About, Collections, Baking Classes and Contact pages, seasonal categories, menus, widgets and comments.

All demo text is original and every demo image is original generated artwork, free to use with the theme.
