# Archform

A monochrome theme for architecture studios: huge project imagery, a concrete-textured paper ground, Instrument Sans with serif italics, a project index, awards table, essays in an index, grid or masonry layout, and an optional dark mode.

Category: **architecture** · Style: Monochrome, concrete texture, huge imagery, grotesk and serif italics

## Highlights

- A full-viewport monochrome hero; the minimal header lies over it on the front page
- A project index table, paired plates, wide plates and an awards table on an ink band
- Essays as a numbered index, a grid or a masonry layout; images in greyscale until hovered
- A concrete texture on the paper ground, an optional dark mode and uppercase titles
- Container width: narrow, wide or full bleed
- Responsive down to 360px with an accessible mobile menu (Escape closes it), visible focus states and `prefers-reduced-motion` support

## Customizer

**Monochrome**: Ink; Paper; Accent; Dark mode (ink ground, paper text); Concrete texture on the page ground; Typefaces.

**Header & Layout**: Header style; Keep the header visible while scrolling; Container width; Uppercase titles; Contact link label; Contact link.

**Front Page**: Hero image; Project label; Heading; Text; Link label; Link URL.

**Journal & Footer**: Post list layout; Sidebar; Show featured images; Show the author on posts and cards; Footer statement; Studio address; Footer text.

## Demo content

Appearance › Themes › Import Demo Content adds 8 posts, 6 pages (Quiet buildings, made to last, Journal, Projects, Studio, Awards, Contact), 4 categories, 12 images, a main menu with submenus, a footer menu, sidebar and footer widgets and the Customizer values shown in the screenshot. The front page is a static page built from blocks; the template `page-wide` is used for full-width pages. All names, firms, addresses and numbers are fictional.
