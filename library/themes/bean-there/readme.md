# Bean There

A specialty coffee shop and café theme in warm espresso browns with a mint accent.

## Features

- Front page hero with a round photo, a “fresh roast” stamp and a call to action
- Opening-hours chip with a live dot in the header (Customize › Café Details)
- Menu Board page template (`page-menu`): a chalkboard panel with dotted price leaders (lists with the class `menu-list`, prices in `<span class="price">`)
- Locations & hours cards, brewing-guide spec cards (`brew-specs`) and numbered steps
- Paper-ticket or dark-tile post cards, grid or list, optional sidebar, dark or light header
- A full-width page template (`page-wide`), accessible focus states, reduced motion, responsive down to 360px

## Customizer

- **Colors & Type** — accent, mint, espresso, background; three type pairings
- **Layout** — header, card style, grid or list, sidebar, featured images, author
- **Café Details** — hours chip on/off and text, front page photo, hero button, footer text

## Demo content

Import it from Appearance › Themes: a café front page, the menu board, Locations & Hours, About, Contact and a journal of brewing guides, bean stories and café news, with menus, widgets and comments.

All demo text is original and every demo image is original generated artwork, free to use with the theme.
