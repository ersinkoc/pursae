# Atelier Nord

A Swiss / International Style portfolio for designers, architects and studios: a strict
twelve-column grid (optionally visible), big grotesk type, a numbered project index with hover
previews, and case studies with a sticky facts column. A static front page presents a statement,
selected work, services, clients and contact as designed sections.

**Category:** Portfolio · **Style:** Swiss grid, big grotesk type

## Customizer

- **Grid & Type:** font pairing (Inter Tight & Plex Mono, Archivo & Plex Mono, system grotesk),
  type scale (compact, regular, display), show the column grid, uppercase labels.
- **Colors:** accent, background and text colors (live preview).
- **Layout:** project list (numbered index, grid, mosaic), header (split or stacked), sticky header,
  author on case studies, front page statement, front page image, footer text.

## Designed sections

Group blocks with the class `an-section` become a labelled row on the grid (the first heading is the
label). Lists with `an-services` and `an-clients`, and paragraphs with `an-statement`, are styled too.

## Demo content

"Form & Fjord", a six-person design studio: eight case studies, a static Home page, Work (posts
page), Studio with an Approach sub-page, and Contact. Text and images are original.
